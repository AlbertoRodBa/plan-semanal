# Plan semanal

## Instalación

1. Clona este repositorio.
2. Entra a la carpeta del proyecto:

```bash
cd plan-semanal
```

3. Instala las dependencias:

```bash
npm install
```

4. Levanta el proyecto en modo desarrollo:

```bash
npm run dev
```

5. Abre la URL que te muestre la terminal, normalmente:

```bash
http://localhost:5173
```

## Build de producción

```bash
npm run build
```

Esto genera la carpeta `dist/` lista para desplegar.
